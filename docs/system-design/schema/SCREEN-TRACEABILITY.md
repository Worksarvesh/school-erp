# Screen → table traceability (draft V1.1)

**Source of screen names:** no Figma frame list was available (the Figma MCP call limit was hit and no exported list was found). Screens below are **derived** from the Scope Report §16 "Navigation and Screen Inventory" and §4–§13, named with its §17.4 convention (`SCHOOL-<ROLE>-<SCREEN>`, `STUDENT-<MODE>-<SCREEN>`). Reconcile with the real Figma frame names when the list is shared; the table rows should map one-to-one.

**API audience** says which API surface serves the screen. The schema and RLS do not change by app: the audience only decides the route family and request context ([RLS-MATRIX.md](RLS-MATRIX.md)).

| Audience                      | Routes                                                                                          | Context  |
| ----------------------------- | ----------------------------------------------------------------------------------------------- | -------- |
| School App                    | `/v1/auth/*`, `/v1/me*`, `/v1/schools/:schoolId/...`                                            | member   |
| Student App - Student         | `/v1/auth/*`, `/v1/me*`, `/v1/schools/:schoolId/me/...`                                         | self     |
| Student App - Parent          | `/v1/auth/otp/*`, `/v1/me*`, `/v1/me/children`, `/v1/schools/:schoolId/children/:studentId/...` | guardian |
| Platform (no app in V1 scope) | `/v1/platform/...`                                                                              | platform |

Status: **V1.1** (in scope) · **Removed** (V1.1 removed it; no tables) · **Changed** (kept but behaves differently from the design scope) · **Gap** (needs data or a decision the schema does not have yet). "Audit" means the screen's write also writes `audit_logs`.
