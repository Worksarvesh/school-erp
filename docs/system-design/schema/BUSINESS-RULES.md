# Business rules → enforcement (draft V1.2)

Each rule from the V1.1 locked decisions as amended by the V1.2 scope decisions and decisions M1–D1 (2026-11-18, `docs/decisions.md`), and where it is enforced. **DB** = constraint, unique index or foreign key. **Trigger** = PostgreSQL trigger. **RLS** = row policy ([RLS-MATRIX.md](RLS-MATRIX.md)). **App** = API service or guard check (with a test). Where a rule can be held by the database, it is; app checks cover what a constraint cannot express.
